Eon’s End RPG — Software Engineering Capstone

Tech Stack: C#, Unity, Azure DevOps, GitHub

Team: 5 members | Agile / Scrum

Project Overview

Eon’s End is a turn-based RPG developed as a year-long capstone project. The focus was on building a reliable, maintainable system while following the full Software Development Life Cycle (SDLC).

My Role

  • Designed and implemented core gameplay logic
  • Developed reusable tools to reduce repetitive code
  • Maintained project documentation and sprint tracking
  • Collaborated with developers, designers, and testers

Testing & Quality Engineering

  • Designed functional test cases for gameplay logic and events
  • Validated data consistency across game states and saves
  • Performed regression testing after feature updates
  • Tracked bugs, tasks, and test results using Azure DevOps
  • Reviewed code for performance, maintainability, and correctness

Results & Impact

Refactoring repetitive systems improved development speed and reduced logic-related bugs. Structured testing helped stabilize gameplay and ensured consistent user experience across updates.
